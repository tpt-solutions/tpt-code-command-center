# Point your tool at TPT

Your coding tool has to send its requests to TPT, with the session token that TPT generated.

- **Claude Code**: copy the environment snippet and paste it into your terminal.
- **Cline**: write Cline's provider settings for you.

[Copy the Claude Code snippet](command:tpt.copyClaudeCodeSnippet)

[Configure Cline](command:tpt.configureCline)

Roo Code, Continue and other tools have guides in the `examples/` folder.
